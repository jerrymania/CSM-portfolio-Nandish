# Nandish C. Mudholkar — Construction Site Management portfolio

Static site (HTML + CSS + JS). No build step needed to deploy.

- Deploy on Vercel: run `vercel` then `vercel --prod` in this folder (framework: Other, no build command), or import the folder from GitHub.
- Pages: `/` home, `/work/ps1` (from the team's PS1 presentation, with all its photographs, layouts and cost tables), `/work/ps2` … `/work/ps6`.
- Edit student details in `assets/js/config.js`.
